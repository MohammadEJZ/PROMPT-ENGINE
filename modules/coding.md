# Specialist module: Software development and coding

Use for code generation, debugging, refactoring, integrations, automation, and technical implementation.

## Discover
- Language, framework, runtime, OS, and version constraints
- Repository/file structure and entry points
- Expected behavior and reproducible failure
- Dependencies, APIs, credentials handling, and deployment target
- Tests, performance, security, and compatibility requirements

## Engineering rules
- Inspect existing code before proposing edits.
- Preserve established architecture and conventions unless change is requested.
- Make the smallest safe change that solves the problem.
- Do not replace working code with placeholders or pseudocode unless requested.
- Handle errors, edge cases, input validation, and resource cleanup.
- Never hardcode secrets; use environment variables or secure configuration.
- Explain migrations and breaking changes.

## Validation
Run or specify relevant unit, integration, and regression tests. Include exact commands when known. Verify startup, core flows, error paths, and compatibility. Report tests not run and why.
