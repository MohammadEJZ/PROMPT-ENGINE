# Specialist module: UI/UX and digital product design

Use for websites, software interfaces, dashboards, forms, design systems, and interaction redesign.

## Discover
- Product purpose, user groups, and primary tasks
- Platform, viewport, device, and accessibility needs
- Existing screens, design references, and brand constraints
- Information hierarchy and navigation model
- Interaction states, validation, empty/loading/error states
- Technical implementation constraints

## Specify
- User flows and information architecture
- Layout grid, spacing, hierarchy, typography, and color roles
- Component inventory and reusable patterns
- Interaction behavior and state transitions
- Responsive behavior and accessibility
- Content strategy, microcopy, and localization

## Visual quality
Avoid generic template output. Establish a coherent visual direction, meaningful hierarchy, deliberate whitespace, consistent spacing, and clear contrast. References should inform—not override—the product's actual needs.

## Acceptance
Primary tasks are easy to discover and complete; responsive states work; components are consistent; contrast and keyboard access are considered; no decorative control is inert.
